# Checklist

## 节点系统
- [ ] 浏览器基础操作节点定义完整（open, goto, click, fill, type, screenshot, waitForSelector, waitForTimeout, close）
- [ ] 流程控制节点定义完整（if, while, foreach）
- [ ] 变量与数据节点定义完整（setVariable, getVariable, extract）
- [ ] 每个节点都有明确的参数配置 Schema
- [ ] 节点类型有对应的图标和颜色区分

## 画布交互
- [ ] 支持从左侧面板拖拽节点到画布
- [ ] 支持节点之间的连线（输出端口到输入端口）
- [ ] 支持画布缩放（滚轮）
- [ ] 支持画布平移（拖拽空白处）
- [ ] 支持节点框选
- [ ] 支持删除节点（Delete 键或右键菜单）
- [ ] 不同节点类型显示不同颜色

## 节点配置
- [ ] 双击节点可打开配置面板
- [ ] 配置面板根据节点类型动态渲染表单
- [ ] 表单字段有适当的输入验证
- [ ] 配置修改后实时更新节点显示

## 流程执行引擎
- [ ] 能将画布节点转换为执行树
- [ ] 支持顺序执行
- [ ] 支持 if 条件分支执行
- [ ] 支持 while 循环执行
- [ ] 支持 foreach 遍历执行
- [ ] 集成 Playwright 实际执行浏览器操作
- [ ] 执行过程中有错误处理机制

## 代码生成
- [ ] 能将可视化流程转换为 Playwright JavaScript 代码
- [ ] 生成的代码可直接运行
- [ ] 支持代码预览
- [ ] 支持复制代码到剪贴板

## 流程持久化
- [ ] 支持将流程保存为 JSON 文件
- [ ] 支持从 JSON 文件加载流程
- [ ] 保存的 JSON 包含完整的节点和连接信息

## 执行结果展示
- [ ] 有执行日志面板实时显示执行状态
- [ ] 执行中的节点有高亮显示
- [ ] 执行成功的节点有成功标记
- [ ] 执行失败的节点有错误标记
- [ ] 执行完成后显示结果摘要

## UI 与交互
- [ ] 顶部工具栏有保存、加载、运行、生成代码按钮
- [ ] 整体布局清晰（左侧面板、中间画布、右侧日志）
- [ ] 有加载状态提示
- [ ] 有错误提示和通知
- [ ] 界面美观、操作流畅
